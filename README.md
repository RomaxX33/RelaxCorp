##### RelaxCorp



Plataforma web desarrollada como Proyecto Final del ciclo formativo de Grado Superior en Administración de Sistemas Informáticos en Red (ASIR).



###### Descripción



RelaxCorp es una plataforma web orientada a la gestión de pausas y descansos durante la jornada laboral mediante diferentes funcionalidades y minijuegos.



El proyecto integra autenticación de usuarios, gestión de cuentas, control del tiempo de uso, estadísticas, rankings y minijuegos.



###### Tecnologías

###### Funcionalidades



\* Inicio y cierre de sesión.

\* Gestión de usuarios.

\* Roles de usuario y administrador.

\* Panel de administración.

\* Creación y eliminación de usuarios.

\* Validación de credenciales.

\* Control del tiempo de uso.

\* Minijuegos.

\* Registro de puntuaciones.

\* Rankings.

\* Estadísticas de usuario.

###### Seguridad



Las contraseñas de los usuarios se almacenan mediante funciones de hash de PHP y las operaciones con la base de datos utilizan consultas preparadas.



Las credenciales de configuración local no se incluyen en el repositorio público.
